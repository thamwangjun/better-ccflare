## End-to-End Flow Verification

OpenRouter response → cost extraction → `providerCostUsd`/`costUsd` → handleEnd gating → `cost_usd` column in `requests` table.

1. **Non-streaming, live path** — `extractUsageInfo()` (provider.ts:274) → response-processor → `updateUsage()` `cost_usd = COALESCE(?, cost_usd)` with `costUsd ?? null`. WIRED.
2. **SSE, worker path** — `extractUsageFromData()` (usage-extraction.ts:164) → `providerCostUsd` → `resolveCostUsd()` gating → `save()` `cost_usd = COALESCE(EXCLUDED.cost_usd, requests.cost_usd)`. WIRED.
3. **Non-streaming, worker path** — `extractUsageFromJson()` (usage-extraction.ts:93) → `providerCostUsd` → `resolveCostUsd()` gating → same persistence. WIRED.
4. **Live streaming, response-processor** — `parseUsage()` (provider.ts:301) → `extractStreamingUsage()` override → real `usage.cost` from SSE message_delta. WIRED.

Genuine `$0` from `:free` models survives both writers (`?? null`, not `|| null`); estimate-`$0` for unknown models collapses to `null` (worker `est === 0 ? undefined` guard in `resolveCostUsd`). Both writers use COALESCE to protect against null-overwrite in the live-then-worker dual-write pattern.
