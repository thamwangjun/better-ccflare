# Phase 260602-8l6 Plan 01: Refactor COST-02/COST-03 Tests Summary

Eliminated the last inline-copy drift risk in the COST-02/COST-03 tests by promoting `parseSSELine` and the `handleEnd()` cost-gating logic (`resolveCostUsd`) into exported pure functions in `usage-extraction.ts`, rewiring both the worker and the two test files to use the real code paths.

## What Was Done

- **Task 1:** Added `export function parseSSELine` (verbatim body from the worker) and `export async function resolveCostUsd(state, estimateCostUSD)` (the D-04 cost-gating logic with the estimate closure injected) to `usage-extraction.ts`. Rewired `post-processor.worker.ts` to import both, deleting its module-private `parseSSELine` and replacing the inline gating block with `await resolveCostUsd(state, () => estimateCostUSD(...))`. The surrounding D-04 comment is preserved. Generated `inline-worker.ts` was NOT touched.
- **Task 2:** Updated both test imports to pull `parseSSELine` / `resolveCostUsd` from `../usage-extraction`, deleted the inline helpers, and left all original cases unchanged. All 6 parseSSELine cases, the 4 sse-parsing gating cases, and the 3 extract-usage gating cases now exercise the real exports.
- **Task 3:** Quality gate run.
