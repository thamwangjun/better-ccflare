<objective>
Implement a public `parseUsage(response)` method on `OpenRouterProvider` so the response-processor streaming branch (guarded by `isStream && ctx.provider.parseUsage`) reaches OpenRouter's real-cost streaming extraction instead of falling through to the non-streaming `extractUsageInfo` branch.

Purpose: Close COST-04 regression risk — a future refactor that stops routing streams through `extractUsageInfo` would silently drop OpenRouter streaming cost. A dedicated `parseUsage` makes streaming cost extraction explicit and contract-correct.
Output: `parseUsage` on `OpenRouterProvider` (OpenRouter-scoped per D-02) plus extended tests.
</objective>
