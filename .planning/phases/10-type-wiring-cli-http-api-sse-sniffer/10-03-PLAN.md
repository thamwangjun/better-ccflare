<objective>
Extend `ANTHROPIC_SHAPE_PROVIDERS` in the SSE rate-limit sniffer to include `"openrouter-anthropic"`, then TDD-verify the change with a synthetic `overloaded_error` fixture.

Purpose: FAIL-01 requires that mid-stream `overloaded_error` frames on `openrouter-anthropic` accounts trigger account failover. The sniffer gates `overloaded_error` matching behind `ANTHROPIC_SHAPE_PROVIDERS` membership. Without this one-line change, `overloaded_error` frames are silently ignored and requests pile up on an overloaded account.

CRITICAL DOC-CONFLICT OVERRIDE: ARCHITECTURE.md §3C incorrectly states the SSE sniffer needs no change for `openrouter-anthropic`. This is WRONG. The `openrouter-anthropic` provider hits OpenRouter's **native Anthropic Messages endpoint** (`/api/v1/messages`) whose SSE stream emits byte-for-byte Anthropic-shape events including genuine `overloaded_error` envelopes. ROADMAP SC#4 ("the sniffer includes the new provider in its shape set") is the authoritative source. D-01 in CONTEXT.md confirms this override. DO NOT revert the `ANTHROPIC_SHAPE_PROVIDERS` extension to match §3C.

Output: One-line sniffer change with a protective comment; two new test cases (positive + negative); existing tests still pass.
</objective>

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-10-03-A | Denial of Service | ANTHROPIC_SHAPE_PROVIDERS membership | accept | Widening the set to include `openrouter-anthropic` makes the sniffer MORE aggressive at detecting overload conditions, which is the desired behavior. No new DoS surface. |
| T-10-03-B | Tampering | SSE frame content triggering failover | accept | The sniffer matches on `overloaded_error` type string. | T-10-03-C | Elevation of Privilege | False positive failover via crafted `overloaded_error` frame | accept | Failover rotates to the next account — not an auth bypass. The consequence of a false positive is a retried request, not a security breach. |
