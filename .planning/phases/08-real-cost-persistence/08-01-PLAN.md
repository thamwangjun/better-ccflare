<objective>
Fix the live streaming OpenRouter cost path so real `usage.cost` from the final SSE
`message_delta` chunk is returned as `costUsd`, instead of the estimate the base class
computes. This closes Gap 1 (D-01/D-02): once the live streaming path returns the SAME
real cost the worker already persists, the dual-writer race becomes harmless by construction.

Purpose: Make the live response-processor streaming path authoritative for real OpenRouter
cost, matching the non-streaming `extractUsageInfo` override already shipped in Phase 7.
Output: An `extractStreamingUsage` override on `OpenRouterProvider` plus its unit tests.
</objective>

| T-7-01 | Tampering | `OpenRouterProvider.extractStreamingUsage` reading `message_delta.usage.cost` | mitigate | `typeof usage.cost === "number"` guard before assigning to `costUsd`; non-numeric/string/object → leave `costUsd` undefined (mirror the established non-streaming guard at `provider.ts:273`).
