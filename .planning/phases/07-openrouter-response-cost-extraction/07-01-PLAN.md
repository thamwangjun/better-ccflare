<objective>
Add `usage.cost` extraction to `OpenRouterProvider.extractUsageInfo()` (per D-01) so non-streaming OpenRouter JSON responses return `costUsd` alongside existing token counts. The field flows automatically through `response-processor.ts` → `ctx.dbOps.updateRequestUsage(requestId, usageInfo)` → `cost_usd` column in the `requests` table. No other files need changes — the existing `updateUsage()` SQL already handles `costUsd` via `COALESCE(?, cost_usd)`.

Purpose: Capture actual USD cost from OpenRouter API responses at the provider level for non-streaming requests.
Output: `extractUsageInfo()` return object includes `costUsd: number | undefined` set from `json.usage.cost`.
</objective>
