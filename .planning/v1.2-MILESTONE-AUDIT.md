## End-to-End Flow Verification

OpenRouter response → cost extraction → `providerCostUsd`/`costUsd` → handleEnd gating → `cost_usd` column in `requests` table.

1. **Non-streaming, live path** — `extractUsageInfo()` (provider.ts) → response-processor → `updateUsage()` `cost_usd = COALESCE(?, cost_usd)` with `costUsd ?? null`. WIRED.
2. **SSE, worker path** — `extractUsageFromData()` → `providerCostUsd` → `handleEnd` gating → `save()` `cost_usd ?? null`. WIRED.
3. **Non-streaming, worker path** — `extractUsageFromJson()` → `providerCostUsd` → same gating/persistence. WIRED.
4. **Live streaming, response-processor** — `parseUsage()` → `extractStreamingUsage()` override → real `usage.cost`. WIRED.

Genuine `$0` from `:free` models survives both writers (`?? null`, not `|| null`); estimate-`$0` for unknown models collapses to `null` (worker `est === 0 ? undefined`).

## Tech Debt (non-blocking, 3 items)

1. **`saveRequest` unconditional overwrite (Phase 8):** `save()` ON CONFLICT writes `cost_usd = EXCLUDED.cost_usd` (`request.repository.ts:87`) while `updateUsage()` uses `COALESCE(?, cost_usd)` (`:148`). On the streaming path the live response-processor (parseUsage → updateUsage, COALESCE-safe) and the worker's later `saveRequest` both write; if the worker's SSE `usage.cost` parse fails and `providerCostUsd` stays undefined, the worker nulls-out a real cost the live path already persisted. Not triggered on the happy path. Fix: change line 87 to `cost_usd = COALESCE(EXCLUDED.cost_usd, cost_usd)`.
2. **Manual live-streaming check (D-05) (Phase 8):** end-to-end USD-in-logs verification remains unperformed by design — requires a free model (`z-ai/glm-4.5-air:free`) force-routed to OpenRouter; NEVER Anthropic or the `claude` account.
3. **Dashboard $0 display (milestone, out of scope):** `RequestDetailsModal.tsx:149` uses raw truthy `summary?.costUsd &&` and `RequestsTab.tsx:886` uses `> 0`, both filtering out genuine $0 costs from `:free` OpenRouter models. Data is correctly persisted; display only. Explicitly out of scope per REQUIREMENTS.md.
