## Cross-Phase Integration

The milestone is a single cost data pipeline spanning both phases. Integration checker confirmed:

- **Non-streaming path:** `OpenRouterProvider.extractUsageInfo()` (Phase 7) → response-processor `extractUsageInfo` branch → `dbOps.updateRequestUsage()` → `RequestRepository.updateUsage()` (`costUsd ?? null`) → `cost_usd` column. WIRED.
- **Streaming path (worker):** worker `extractUsageFromData()` (SSE message_delta) → `providerCostUsd` → `handleEnd()` gating → `state.usage.costUsd` → `saveRequest()` → `RequestRepository.save()` (`costUsd ?? null`) → `cost_usd` column. WIRED.
- **Streaming path (live):** `OpenRouterProvider.extractStreamingUsage` override (clone-before-delegate + `readFinalSseCost`, Phase 8) → real `usage.cost`. WIRED.
- **$0 distinction:** real provider $0 persists as `0` (`?? null`); estimate-$0 for unknown models collapses to `NULL` (worker `est === 0 ? undefined`). Consistent end-to-end; no later layer re-estimates or overwrites incorrectly (COALESCE / ON-CONFLICT interaction reviewed, derives the same value).
- **Non-OpenRouter regression:** `providerCostUsd` only set behind `typeof === "number"` guard; absent for other providers → estimate fallback runs unchanged. No regression.
