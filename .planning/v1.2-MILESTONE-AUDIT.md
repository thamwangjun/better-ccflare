## End-to-End Flow Verification

OpenRouter response → cost extraction → `providerCostUsd`/`costUsd` → handleEnd gating → `cost_usd` column in `requests` table.

1. **Non-streaming, live path** — `extractUsageInfo()` (provider.ts) → response-processor → `updateUsage()` `cost_usd = COALESCE(?, cost_usd)` with `costUsd ?? null`. WIRED.
2. **SSE, worker path** — `extractUsageFromData()` → `providerCostUsd` → `handleEnd` gating → `save()` `cost_usd ?? null`. WIRED.
3. **Non-streaming, worker path** — `extractUsageFromJson()` → `providerCostUsd` → same gating/persistence. WIRED.
4. **Live streaming, response-processor** — `parseUsage()` → `extractStreamingUsage()` override → real `usage.cost`. WIRED.

Genuine `$0` from `:free` models survives both writers (`?? null`, not `|| null`); estimate-`$0` for unknown models collapses to `null` (worker `est === 0 ? undefined`).

## Tech Debt (non-blocking)

1. **Inline-copy tests (Phase 7):** COST-02/COST-03 unit tests exercise inline copies of the extraction functions, not the production worker exports. Production behavior independently verified; risk is silent drift. Consider exporting and testing the real functions.
2. **Dual-path cost derivation (Phase 8):** Worker and live response-processor both write `cost_usd` for the same request via independent code. Convergent and safe today (same source value, no double-count); divergence-prone under future edits. Consider consolidating to a single derivation.
3. **Pre-existing unrelated test failures:** `account-openrouter-preference.test.ts` fails on a missing `consecutive_rate_limits` column (AccountRepository test-fixture schema gap). Not introduced by v1.2; out of milestone scope but worth a follow-up.
